# Contributing

Thank you for your interest in KIOTA IoT Telemetry Core.

## Before contributing

- Open an issue to discuss substantial changes.
- Keep pull requests focused and explain the engineering motivation.
- Include tests for new behavior and regression fixes.
- Update documentation when APIs, schemas, configuration, or behavior change.
- Never commit credentials, private keys, production telemetry, or personal data.

## Pull request checklist

- [ ] The change has a clear description and scope.
- [ ] Relevant tests have been added or updated.
- [ ] Documentation has been updated.
- [ ] No secrets or sensitive data are included.
- [ ] Compatibility and failure behavior have been considered.

Be respectful and constructive in all project discussions.
